API Reference

Quick reference for the Sticky Fig DSL

FunctionDescriptionExample
figure(name, opts)Create a stick figure characterfigure('Alice', { expression: 'happy', pose: POSES.waving, x: 100, y: 150 })
pose(opts)Create a custom posepose({ leftArm: {shoulder: 30, elbow: -20} })
bubble(text, opts)Create a speech bubblebubble('Hello!', { x: 140, y: 30, tailX: 100, tailY: 70 })
panel(opts)Create a comic panelpanel({ figures: [...], bubbles: [...], caption: 'Later...' })
strip(opts)Create a comic stripstrip({ title: 'My Comic', layout: 'row', width: 800 })

Example Code

const { figure, POSES, bubble, panel, strip } = StickyFig const alice = figure('Alice', { expression: 'happy', pose: POSES.waving, x: 80, y: 150, hair: 'long', }) const comic = strip({ title: 'My Comic', width: 800 }) comic .addPanel(panel({ figures: [alice], bubbles: [bubble('Hello!', { x: 140, y: 30 })], })) .addPanel(panel({ figures: [figure('Bob', { expression: 'surprised', x: 100, y: 150 })], bubbles: [bubble('Oh!', { x: 140, y: 30, style: 'shout' })], background: '#ffebee', })) const svg = comic.render() // returns SVG string
